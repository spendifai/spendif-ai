Installation et premier lancement

Trois étapes pour faire fonctionner Spendif.ai sur votre ordinateur : télécharger, installer, premier lancement. Tout en local, sans compte.

✨Ce que vous obtenez

  • Importe les CSV/XLSX de n'importe quelle banque — détecte automatiquement le format, pas de mapping manuel
  • Catégorisation par IA, totalement hors ligne — LLM local inclus, pas besoin de cloud
  • IA locale par défaut — les données restent sur votre machine ; le LLM distant est opt-in et masque IBAN / cartes / noms du titulaire (les montants et les dates voyagent toujours — voir feuille de route)
  • Cinq langues — italien, anglais, français, allemand, espagnol
  • Réconciliation carte-compte (bêta) — apparie les débits carte avec les dépenses sous-jacentes pour éviter le double comptage(cas limites encore en cours de raffinement)
  • Détection des virements internes (bêta) — apparie les virements entre vos propres comptes pour qu'ils ne gonflent pas les tableaux de bord(cas limites encore en cours de raffinement)

2Installer

macOS — DMG

1. Double-cliquez sur le fichier .dmg téléchargé.

2. Glissez Spendif.ai.app dans le dossier Applications.

3. Éjectez le DMG (Cmd+E) et lancez l'app depuis Launchpad.

Si vous voyez "Impossible d'ouvrir Spendif.ai car le développeur ne peut pas être vérifié" (build pas encore signée) : clic droit sur l'app → Ouvrir → confirmer.

Ou bien, avec Homebrew :

brew tap spendifai/spendifai
brew trust --cask spendifai/spendifai/spendifai
brew install --cask --no-quarantine spendifai

Ensuite, vous mettez à jour avec brew update && brew upgrade --cask spendifai.

3Premier lancement

Au premier lancement, Spendif.ai prépare son environnement — c'est l'étape la plus longue, mais elle n'arrive qu'une fois.

⏱ Temps requis : 5–15 minutes sur une connexion domestique typique. Espace libre requis : ~5 Go.
Gardez la fenêtre ouverte jusqu'à ce que la barre de progression disparaisse.

3a. Splash + téléchargement du modèle IA

Double-cliquer ouvre une fenêtre native avec un écran de démarrage et une barre de progression. Spendif.ai détecte la RAM/VRAM disponible et télécharge le LLM le plus adapté (Qwen 2.5, Gemma 3 — tailles de 2 à 8 Go).

Le modèle est stocké dans ~/.spendifai/models/ (macOS/Linux) ou %APPDATA%\Spendif.ai\models\ (Windows) et survit aux réinstallations.

3b. Assistant d'onboarding — 4 étapes

Une fois le modèle prêt, le splash laisse place à l'assistant de configuration :

1. Langue — taxonomie, format de date, séparateurs numériques.
2. Titulaires — votre nom et les variantes utilisées par la banque.
3. Comptes — compte courant, cartes, espèces.
4. Confirmer — tout est écrit ici uniquement, pas de persistance partielle.

Aucun choix n'est définitif : tout peut être modifié plus tard depuis Paramètres.

3c. App prête

À la confirmation, Spendif.ai crée la base SQLite et vous emmène sur la page Importer. Depuis là, vous chargez vos premiers CSV/XLSX bancaires.

Aux lancements suivants : double-clic → splash (1-2 secondes) → app. Plus de téléchargements, plus d'assistant.

Ce qui arrive ensuite

Spendif.ai est en alpha. Les fonctionnalités que nous ajouterons seront décidées avec les personnes qui utilisent l'app aujourd'hui : pas de travail spéculatif, pas de roadmap imposée d'en haut.

Fonctionnalités à l'étude selon les retours des alpha testeurs :

  • Suivi du cash — enregistrer manuellement les dépenses en espèces, sans relevé bancaire
  • Performance des investissements — voir d'un coup d'œil comment les instruments de votre portefeuille évoluent
  • App mobile compagne — saisir les espèces à la volée depuis le téléphone et synchroniser avec le bureau

L'une de ces options vous serait-elle utile ? Dites-le-nous sur GitHub Discussions. Quand suffisamment de demandes s'accumulent sur la même fonctionnalité, elle monte en tête de file.
