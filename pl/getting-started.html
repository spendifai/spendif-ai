Instalacja i pierwsze uruchomienie

Trzy kroki, aby uruchomić Spendif.ai na komputerze: pobierz, zainstaluj, pierwsze uruchomienie. Wszystko offline, bez konta.

✨Co otrzymujesz

  • Importuje CSV/XLSX z dowolnego banku: automatyczne rozpoznawanie formatu, bez ręcznego mapowania
  • Kategoryzacja AI, w pełni offline: lokalny LLM w zestawie, chmura nie jest potrzebna
  • Lokalna AI domyślnie: dane pozostają na Twoim komputerze; zdalny LLM jest opt-in i redaguje IBAN / karty / nazwiska właścicieli (kwoty i daty nadal podróżują: zobacz roadmap)
  • Pięć języków: włoski, angielski, francuski, niemiecki, hiszpański
  • Uzgadnianie karta-konto (beta): paruje obciążenia kartą z pierwotnymi wydatkami, aby uniknąć podwójnego liczenia(przypadki brzegowe są jeszcze dopracowywane)
  • Wykrywanie transferów wewnętrznych (beta): dopasowuje transfery między Twoimi kontami, aby nie zawyżały dashboardów(przypadki brzegowe są jeszcze dopracowywane)

2Instaluj

macOS: DMG

1. Kliknij dwukrotnie pobrany plik .dmg.

2. Przeciągnij Spendif.ai.app do folderu Programy.

3. Wysuń DMG (Cmd+E) i uruchom aplikację z Launchpada.

DMG jest podpisany certyfikatem Developer ID i notaryzowany przez Apple: macOS otwiera go bez ostrzeżeń.

Alternatywnie, przez Homebrew:

brew tap spendifai/spendifai
brew trust --cask spendifai/spendifai/spendifai
brew install --cask spendifai

Od tej pory aktualizujesz przez brew update && brew upgrade --cask spendifai.

Windows: MSIX

1. Kliknij dwukrotnie pobrany plik .msix.

2. Otworzy się wbudowany Instalator Aplikacji Windows. Kliknij Zainstaluj.

3. Aplikacja pojawi się w Menu Start: uruchom ją stamtąd.

Przez pierwsze kilka razy Windows może pokazać "System Windows ochronił Twój komputer": kliknij "Więcej informacji", a następnie "Uruchom mimo to". Ostrzeżenie znika, gdy certyfikat zbuduje reputację. Szczegóły w przewodniku.

Z terminala:

3Pierwsze uruchomienie

Przy pierwszym uruchomieniu Spendif.ai konfiguruje środowisko: to najdłuższy krok, ale wykonywany tylko raz.

⏱ Wymagany czas: 5-15 minut na typowym domowym łączu. Wymagane wolne miejsce: ~5 GB.
Trzymaj okno otwarte, dopóki pasek postępu nie zniknie.

3a. Splash + pobieranie modelu AI

Podwójne kliknięcie otwiera natywne okno z ekranem powitalnym i paskiem postępu. Spendif.ai wykrywa dostępny RAM/VRAM i pobiera najbardziej odpowiedni LLM (Qwen 2.5, Gemma 3: rozmiary od 2 do 8 GB).

Model trafia do ~/.spendifai/models/ (macOS/Linux) lub %APPDATA%\Spendif.ai\models\ (Windows) i przetrwa reinstalacje.

📷 Zrzut ekranu
assets/screenshots/splash-download-progress.png

3b. Kreator wprowadzający: 4 kroki

Gdy model jest gotowy, splash ustępuje miejsca kreatorowi konfiguracji:

1. Język: taksonomia, format daty, separatory liczbowe.
2. Właściciele: Twoje imię i warianty używane przez bank.
3. Konta: konto bieżące, karty, gotówka.
4. Potwierdź: wszystko jest zapisywane tylko tutaj, brak częściowej trwałości.

Żaden wybór nie jest ostateczny: możesz zmienić wszystko później w Ustawieniach.

3c. Aplikacja gotowa

Po potwierdzeniu Spendif.ai tworzy bazę SQLite i przenosi Cię do strony Import. Stamtąd ładujesz pierwsze pliki CSV/XLSX z banku.

Przy kolejnych uruchomieniach przebieg to: podwójne kliknięcie → splash (1-2 sekundy) → aplikacja. Bez pobierania, bez kreatora.

Odinstalowanie

Nic nie zostaje na komputerze wbrew Twojej woli. Polecenie zależy od sposobu instalacji:

Nie pamiętasz, jak instalowałeś? Jeśli używałeś Terminala, to był Homebrew, w przeciwnym razie DMG.

macOS, Homebrew: brew uninstall --cask spendifai

macOS, DMG: przeciągnij Spendif.ai.app do Kosza

Debian / Ubuntu: sudo apt remove spendifai

Fedora / RHEL: sudo dnf remove spendifai

Windows: Ustawienia > Aplikacje > Spendif.ai > Odinstaluj

Twoje dane pozostają, i tak ma być. W ~/.spendifai (w Windows %USERPROFILE%\.spendifai) znajdują się baza transakcji, ustawienia i modele AI, w sumie kilka GB. Żadne z powyższych poleceń ich nie usuwa.

Przed usunięciem wyeksportuj to, co chcesz zachować, ze strony Ledger: po usunięciu nie da się tego odzyskać.

Aby usunąć także dane: w Homebrew brew uninstall --zap --cask spendifai. W pozostałych przypadkach użyj deinstalatora dla swojego systemu (macOS, Linux, Windows), który pyta osobno o bazę danych i o modele, albo usuń folder ręcznie.
